# Landmark program ids — the known universe, so the index is not limited to
# whatever happened to deploy inside the poller's window.
#
# WHY THIS FILE EXISTS
#   The index is built from loader events. A program that has not deployed or
#   upgraded since ingestion started has no row at all, so it is unsearchable
#   AND absent from the fingerprint corpus. The second half is the real cost:
#   TLSH lineage can only recognise a new deploy as a fork of Raydium CLMM if
#   Raydium CLMM is in the corpus. Measured against a public list of 250
#   well-known mainnet programs, On Record held 70 — 170 ordinary upgradeable
#   programs were missing purely for want of a recent event.
#
# WHAT IS AND IS NOT HERE
#   Addresses only. Names and categories are deliberately absent: an address is
#   a public on-chain fact, a curated label is somebody's editorial work, and
#   this file is an ingestion target list, not a registry. Names come from the
#   binary as they do for every other program; curated names live in
#   packages/enrich/labels.yaml, which is a separate decision.
#   Section headers are navigation aids, not claims — nothing reads them.
#
#   Excluded on purpose: native-loader programs (Vote, Compute Budget) have no
#   bytecode on chain to fingerprint, and two entries on the source list are not
#   mainnet programs at all (one is Pythnet-only, one is a PDA).
#
#   The immutable loader-v1/v2 programs (SPL Token, Memo, ATA, Serum v2, Orca
#   v1) ARE here: their program account holds the ELF directly, which
#   seed-landmarks.ts now reads. They are ingested undated — see EventEnrichment.
#
# Seeded from the public program list at https://orbmarkets.io/programs
# (addresses re-verified against chain: owner + executable, 2026-07-31).
#
#   ./node_modules/.bin/tsx src/seed-landmarks.ts [--dry]
